# Talent Search

Talent Search finds US clinicians from a plain-English description. No special words or filters needed.

![Talent Search](/resources/search.png)

---

## Where to search

- **Talent Search** in the left sidebar. If you are not in a project, Oslr makes a project for the search so you can come back to it.
- **Inside a project**: the **Talent Search** tab or the box on the Candidates page. Results save into that project.

## What to type

Say who, where and anything that matters:

- *Interventional pain physicians in Phoenix, Arizona*
- *Orthopedic surgeons at Panorama Orthopedics in Colorado*
- *ICU nurses with a BSN near Chicago*
- *PGY-4 and PGY-5 orthopedic residents graduating in Texas*
- *Nurse practitioners in family medicine in Atlanta*

Oslr picks out the role, specialty, location, current or past employer, credentials (MD, DO, NP, PA-C, CRNA, RN...), training stage (resident, fellow) and years of experience.

Oslr is for clinical roles only. Searches for sales or office roles will not return useful results.

## Reading results

Results are ranked best match first. Each row shows the clinician, current role and employer, location and a **match** score. Results load in pages; the next page is prepared in the background so it opens fast.

### Match criteria

After a search Oslr turns your description into a list of **criteria** (for example *Practices interventional pain*, *Based in Arizona*). Each clinician gets an answer for each one:

| Answer | Meaning |
|---|---|
| **Yes** | Their profile shows it |
| **Partly** | Some of it shows |
| **Not shown** | Nothing in their profile either way |
| **No** | Their profile shows otherwise |

You can **reorder** criteria by dragging, mark one as a **must-have**, edit, add or remove criteria. The ranking updates instantly, at no cost.

### Table view

Switch to the table to compare many clinicians side by side. The name column stays put while you scroll; hover an answer to see why.

## Saving

Click **Save** on any clinician to add them to the project. Saved clinicians also appear in **Contacts**.

## Cost

Searching is free. Opening the same search again within 90 days uses saved results. Credits are used only for contact info. See [Credits](/resources/credits).
