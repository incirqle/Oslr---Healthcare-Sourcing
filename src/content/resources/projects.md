# Projects

A project is one role you are hiring for. Every search, saved clinician, agent and live sync for that role lives inside it, so nothing gets lost.

![The Projects list](/resources/projects.png)

---

## The Projects list

At the top: total **Projects**, **Candidates saved**, **Searches run** and **Agents working**.

Each row shows the project name, how many searches it has, when it was last active, its agent status (for example **Learning**), and counts for **Saved**, **Contacted** and **Interested**, plus the owner. Use **Find a project** to search by name, or **With agents** to show only projects that have an agent.

## Making a project

1. Click **New project** (top right).
2. Name it after the role, for example *Iowa orthopedics*.
3. Add a short description if you like, for example *Interventional pain physicians in Arizona*.

Tip: clicking **New search** from the Projects list and running a search also creates a project for you, named from your search.

## Inside a project

![Inside a project](/resources/project-detail.png)

- **Search box**: *Describe who you need for this role.* Choose **Search** for a one-time search, or **Agent** to start an agent with that description.
- **Searches**: every search run in this project, with match count, when and by whom. Click the circular arrow to reopen it. Reopening uses saved results, so it is instant and free for 90 days.
- **Team** (right side): owner, who it is shared with, **Add teammates**, and created date.
- **Connections** (right side): **Live sync** to Sheets, Slack or Excel, and **ATS / CRM** connect.
- **Agents** (right side): agents on this project and their status.
- **Pipeline cards** at the bottom: how many clinicians are saved, contacted, interested and so on.

Other buttons: **View in Contacts** shows this project's clinicians in the Contacts table; **Source Candidates** opens Talent Search for this project; the pencil next to the name renames it.

## Sharing

Projects are shared with your whole workspace. Teammates see the same projects, clinicians and history.

## Where are my old searches?

Searches run before a search was tied to a project, or with the project set to *None*, do not show inside a project. Every new search is saved to its project.
